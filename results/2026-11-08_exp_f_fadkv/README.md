# 2026-11-08 实验 F：FAD-KV —— 跨层 KV 的功能蒸馏压缩（阶段一）

**目标**：把 L6~35 的原生 KV（61440 维，120 KiB/token）压到 2 KiB/token（60 倍），
同时把 EM 从实验 E 全局 PCA-1024 的 23.5% 拉向原生 KV 的 45.5%。

**方法（阶段一：通道压缩，序列长度不变）**
- L6~35 按"层段 × K/V"切成 3 段 × {K,V} 共 6 组（层段**交错**切分，每段都覆盖深浅层）
- 每组一个独立线性编解码器，总潜码 1024 维（bf16 = 2 KiB）
- `W_enc` 初始化为该组分组 PCA 基底、`W_dec` 为其转置 → **第 0 步严格等于分组 PCA**
- 损失 `L = L_QA + λ_kv·L_kv + λ_kl·L_KL + λ_attn·L_attn`，主干冻结，只训 codec（21M 参数）
- 预算分配 **K 102 维 / V 239 维**（不是对半分）
- 步数 **750**

代码 `fadkv_codec.py` / `train_fadkv.py` / `eval_fadkv.py` / `kv_lowrank.py`（分组基底），
启动 `runs/exp_f_fadkv.sh`。200 题，逐题 EM 用归一化整串相等，F1 用 HotpotQA 官方口径。

## 主表（n=200，统一 full_prefix 协议）

| 方法 | 存储 KiB/token | 序列保留率 | EM% | F1% | 相对原生 |
|---|---|---|---|---|---|
| `native`（原生 L6~35 KV） | 120 | 100% | 45.5 | 65.3 | 100% |
| `pca1024`（实验 E 全局基） | 2.0 | 100% | 23.5 | 39.7 | 52% |
| **`fadkv1`（本方法）** | **2.0** | **100%** | **41.0** | **59.5** | **90%** |
| `fadkv1_wrong`（换成别的题） | — | — | 10.0 | 15.7 | 22% |

配对（vs `native`）：`fadkv1` 差 −4.5（28 vs 37，p=**0.3211**，统计上已分不出差别）；
`pca1024` 差 −22.0（1 vs 45，p<0.0001）；`fadkv1` vs 自己的 wrong：+31.0（p<0.0001）。

## 四步怎么走到 41.0% 的

| 配法 | EM% | 说明 |
|---|---|---|
| 分组 PCA，零训练 | 5.5 | 初始化不能直接用（EM 与 wrong 都是 5.5，记忆不生效） |
| K/V 对半分 171+171，1000 步 | 28.0 | 训练能从坏起点爬出来 |
| 预算偏 V（K 102/V 239），1000 步 | 32.5 | 同一 1024 维总量，改分配 +4.5 |
| 再加 `L_attn`，**750 步** | **41.0** | +8.5；1000 步反而退化到 34.5（过拟合） |

两个支撑诊断：

1. `tools/diag_kv_by_type.py`：压缩误差按 token 类型/层段分层。实体 token 占 19.4%、
   承担 27.0% 的误差（放大 1.39×，只是略超载）；**Value 的相对误差 80.8% 是 Key
   47~52% 的 1.6 倍**，吃掉 67% 总误差 —— 于是改成预算偏 V。
2. 训练过程中 `L_kv` 从 0.22 涨到 0.44，而 EM 从 5.5 涨到 28.0：**KV 重建更准 ≠ 读得
   更对**。这正是加 `L_attn`（约束被注入层的注意力输出）的依据。

## 采信限定

- 主干为冻结纯 Qwen3-4B-Instruct-2507（无 adapter），bf16，生成不走 KV cache
- 步数 750 是**单点**，700/800 附近未扫；1000 步已知退化（`L_attn` 0.90 → 1.27）
- `number` n=7、`date` n=11 不可单独引用（数字题 71.4% 高于原生是 7 题里 5 题的偶然）；
  实体 166 题是主线
- 本轮压的是**表示维度**；序列长度压缩（锚点 + 池化，阶段二）未做
- 分段 PCA 本身弱于全局 PCA（同维数下重建误差 46.7% vs 34.7%）：跨层冗余是主要可压缩性
  来源，切段等于放弃共享。收益来自训练，不是来自分组
