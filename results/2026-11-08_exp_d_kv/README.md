# 2026-11-08 实验 D：恢复真实 KV 的明文读取能力（零训练）

**方法定义**：把完整 prompt 按 token 切成 `S`（证据前的固定段）/ `E`（金标证据）/ `T`（证据后
的一切）。离线只编码 `S+E`、只取 `E` 那段的逐层 KV；在线只喂 `S+T`（`E` 不进残差流），把它的
KV 插回原逻辑位置。主干冻结，零训练，不压缩。

代码 `midlayer_kv.py` / `eval_midlayer_kv.py`，启动 `runs/exp_d_kv_recovery.sh`。
200 题，`hotpot_val500` 前 200 条，EM = 归一化整串相等；所有臂共用同一个贪心解码函数。

## 三条结论

1. **D0 通过（计算等价，不是近似）**：全 36 层注入真实逐层 KV，与明文前向逐题相同。
   实验 C 的 21.0% 因此不是接口实现问题。
2. **D1：只要一个固定短锚点，不需要原始上下文**。`bare` 掉 10.5 点（p<0.0001），
   而 `"Memory:\n- "` 两 token 锚点只差 1.0 点（p=0.69，不显著）。锚点不含未来问题，
   写入仍可提前做、可复用，不违反 Query-Agnostic。
3. **D2：必须从第 6 层起接触证据**。L0 53.0 → L6 45.5（86%，过 45% 门槛）→ L12 22.5
   → L18 1.5。**“从 L12 开始读”不成立**；后续要压的是第 6~35 层的 KV。

**未解的矛盾（右端不可信之前先查）**：`kv:full_prefix:18` = 1.5 低于不给记忆（9.5），
也远低于实验 C 同层位的 `upper_kv` 21.0。两者都注入 18~35 层的真实逐层 KV，差别可能在
“记忆整段放在所有 token 之前”（C）vs“插在 S 与 T 中间”（D）。L0/L6/L12 三档不受影响。
