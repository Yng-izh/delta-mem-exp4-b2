# 2026-11-07 实验 C：中间层原生 KV 读出（零训练）

**方法定义**：记忆不回输入层。证据过冻结主干的 0~17 层得到 H¹⁸（逐 token，不压缩），
由**第 18~35 层各自的** `k_proj/v_proj`（+ `input_layernorm` + `k_norm` + RoPE）投影成
该层 K/V，交给该层**原生注意力**读。主干权重全部冻结，无任何训练。
代码：`midlayer_kv.py` / `eval_midlayer_kv.py`，启动：`runs/exp_c_kv_readout.sh`。

**运行**（GPU 1，200 题，475 秒）

```bash
PY=<envs/knowlearn_data/bin/python> GPU=1 LIMIT=200 TAG=exp_c_200 bash runs/exp_c_kv_readout.sh
```

## 结果

| arm | 记忆 | EM% |
|---|---|---|
| `none` | 不给 | 9.5 |
| `oracle_text` | 明文证据进 system | 52.5 |
| `upper_kv` | 18~35 层**真实逐层** K/V | **21.0** |

## 判读

1. **接口成立**：21.0 对错记忆 8.5（28 比 3，p<0.0001）。不是"多给上下文"的错觉。
2. **单层不够**：14.5 也显著高于错记忆，但比逐层低 6.5 点（p=0.011）。
3. **适配器天花板 = 21.0%**：真实逐层 KV 是任何完美适配器的产出上界，训适配器最多
   把 14.5 补到 21，拿不到"给原文"那 52.5 里剩下的 31.5 点。
4. 31.5 点的缺口尚未归因，候选是"注入太晚（前 18 层看不到证据）"与"单向编码（写入时
   没见过问题）"，用 `--start-layer` 0/6/12/18 扫描可切开。

## 中途修掉的一个致命 bug（记录在此，避免复现）

第一版把**未归一化的残差流**直接喂进 `k_proj/v_proj`，漏了该层的 `input_layernorm`。
后果是注意力输出范数 1008（真·前缀拼接为 10），残差流被冲掉，**连"给真实逐层 KV"
那一臂也全是乱码**——极易被误读成"高层读不了记忆"。修好后该项降到 8.4，下一个 token
回到正常英文。教训：`hidden_states[l]` 是残差流，不是这一层注意力的输入。
