# 实验 A：完整隐藏状态 + Query-conditioned Reader（1000 步，失败）

一句话：**Reader 学会了在训练集上复述与答题，但验证集上五个读出（none / shuffle /
wrong / full / oracle_text）里前四个完全一样 —— 输入层软 token 这条路走不通。**

## 设置

| 项 | 值 |
|---|---|
| 记忆 | 金标证据第 18 层**逐 token 隐藏状态**（不压缩，每题 70~150 个位置） |
| Reader | 输入 LayerNorm + 逐 token 问题条件化投影 + 整向量 L2 对齐（2.7M 参数） |
| 训练目标 | `L = L_QA + 0.5 · L_fact_recon`（只在事实关键位算，前缀随机破坏） |
| 数据 | `hotpot_train_10k` 前 9997 条；验证 `hotpot_val500` 前 40 题 |

## 结果（EM，40 题）

| step | none | shuffle | **wrong** | **full** | oracle_text |
|---|---|---|---|---|---|
| 250 | 17.5 | 17.5 | 22.5 | 20.0 | 55.0 |
| 500 | 17.5 | 20.0 | 20.0 | 22.5 | 55.0 |
| 750 | 17.5 | 20.0 | 17.5 | 20.0 | 55.0 |
| 1000 | 17.5 | 20.0 | 20.0 | 20.0 | 55.0 |

`full − wrong` 在 ±2.5 之间来回（40 题 = 1 道题），**没有任何可用信号**。

## 关键矛盾：训练损失正常下降，验证集不动

| step | `loss_qa` | `loss_recon` |
|---|---|---|
| 20 | 1.40 | 10.75 |
| 300 | 1.38 | 10.50 |
| 1000 | **0.19** | **1.16** |

重建损失从 ~10 降到 1.16 —— **训练集上它确实能"复述证据"了**。但验证集的 `full`
一步没动。这是**记住了训练集、没学到可泛化的翻译**的典型形态：2.7M 参数、约 4000 个
样本，不足以学会"2560 维隐藏状态 → 输入词向量空间"这个映射。

## 因此得到的判断

按预定判据（"若依然无法读取完整隐藏状态，就有理由放弃输入层软 Token"）：

- 旧结构（残差 + 零初始化）750 步失败，且实测上游梯度恰好为 0；
- 新结构（LayerNorm + 直接投影 + 密集事实监督）1000 步**仍然失败**，且训练损失正常下降。

两次独立失败 ⇒ **问题不在训练不足，在接口本身**：把第 18 层的上下文化表示翻译回
第 0 层词向量，这个跨空间转换在当前监督量与参数量下学不出来。

下一步应转向**中间层读取**：把第 18 层当中间层记忆，用轻量 Cross-Attention / KV
读取模块与冻结主干交互，避免跨空间翻译。

## 限制

- 40 题，EM 粒度 2.5%（1 道题）—— 但**四个读出挤在同一个数上**这件事不受粒度影响。
- 单 seed、单配置（bottleneck 256、lr 2e-4）。
- 复现：`bash runs/exp_a_reader.sh`（日志 `logs/2026-11-06/expA_reader_1000_recon0.5.log`）
